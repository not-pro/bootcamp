# Vite+ Monorepo Starter

Стартовый шаблон для Vite+ monorepo.

## Структура монорепозитория

| Пакет               | Описание                                                                           |
| ------------------- | ---------------------------------------------------------------------------------- |
| `apps/tv-shows`     | Исходный код приложения TV Shows — SPA на React + Vite для просмотра сериалов.     |
| `packages/useQuery` | Внутренняя библиотека для выполнения запросов (обёртка над React Query / `fetch`). |

## Структура `apps/tv-shows` — исходный код

```
apps/tv-shows/src/
├── app/
│   └── index.tsx          — Точка входа приложения и корневой компонент
├── assets/                — Статические ресурсы (изображения, шрифты и т.д.)
├── config/
│   └── const.ts           — Константы приложения (URL API, настройки)
├── hooks/
│   ├── index.ts           — Групповая экспорт-обёртка (barrel)
│   └── useDebounce.ts     — Общий хук с debounce-логикой
├── pages/
│   └── home-page/
│       ├── home-page.tsx  — Главная страница
│       ├── contexts/      — Контекст и провайдер HomePage
│       └── components/
│           ├── card-show/ — Карточка отдельного сериала
│           ├── content/   — Контентная сетка с пагинацией
│           ├── filter/    — Панель фильтров
│           └── search/    — Поле поиска и результаты

    ├── button/            — Переиспользуемая кнопка
    ├── card/              — Базовая карточка + плейсхолдер для изображения
    ├── catalog-layout/    — Обёртка для страницы каталога
```

## Запуск проекта

### Требования

- **Node.js** ≥ 22.18.0
- **pnpm** 12.18.0 (скачается автоматически, если отсутствует)

### Установка и запуск

```bash
# 1. Установить зависимости
pnpm install

# 2. Запустить полную проверку (линтинг, типизация, тесты, сборка)
pnpm run ready

# 3. Запустить режим разработки
pnpm run dev
```

Dev-сервер запустится по адресу `http://localhost:5173`.

### Доступные скрипты

| Скрипт              | Описание                                                                |
| ------------------- | ----------------------------------------------------------------------- |
| `pnpm run ready`    | Запустить линтинг, проверку типов, тесты и сборку всего монорепозитория |
| `pnpm run dev`      | Запустить dev-сервер для `tv-shows`                                     |
| `pnpm run -r test`  | Запустить тесты во всех пакетах                                         |
| `pnpm run -r build` | Собрать все пакеты                                                      |
