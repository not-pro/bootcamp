# useQuery

Учебный React-хук для GET-запросов и общего кеша в памяти.

```ts
import { setupBaseUrl, useQuery } from "useQuery";

// Один раз перед запуском приложения.
setupBaseUrl("https://example.com");

// Внутри компонента или другого хука.
const result = useQuery<number>({
  queryKey: "count",
  endpoint: "/count",
  onSuccess: (count) => console.log(count),
});
```

- `cache-first` (по умолчанию) возвращает запись из кеша. При промахе делает
  запрос и сохраняет ответ в памяти.
- `cache-only` читает только кеш. При промахе возвращает
  `data: undefined`, `loading: false`, `error: null`; сеть не используется.
- `network-only` всегда делает запрос с `cache: "no-store"` и сохраняет ответ.
- Тип `Data` задаётся через `useQuery<Data>`. Структура JSON во время выполнения
  не проверяется: указанный тип должен соответствовать ответу сервера.
- Запись кеша определяется парой `[queryKey, полный URL]`.
- При новом запросе старые данные и ошибка очищаются. После запуска эффекта
  `loading` равен `true` для сетевого запроса, после завершения — `false`.
- Смена URL, ключа, политики перезапускает эффект.
  Изменение `onSuccess` и `onError` не перезапускает запрос: используется
  последняя версия обработчика.
- Отменённый запрос не меняет состояние, кеш и не вызывает обработчики.
- `onSuccess` вызывается и при успешном чтении кеша; при промахе не вызывается.
- `error` имеет тип `unknown`; прежде чем читать `message`, проверь `instanceof Error`.

TTL, подписки на изменения общего кеша, refetch и автоматические повторы
пока не реализованы. Неиспользуемые опции refetch убраны из контракта.
